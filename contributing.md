# Contributions
Contributions are welcome, as long as they follow the testing policy and use the given template.

## Testing Policy
To be merged, you must build the project, and test your work on a server, either by running a command through the console, testing it in-game, or both.

## Pull Request Template
The following template may be copied and pasted into a PR. PRs without this information will be ignored.
```md
## Summary
What did you change?

## Category
What categories does this PR fall under? Documentation, feature, bugfix, etc.

## Testing methodology
How did you test your code to make sure it worked? Make sure you've followed the Testing Policy. 
```
